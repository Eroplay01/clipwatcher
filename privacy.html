Privacy Policy

Last updated: November 17, 2026

ClipWatcher is a desktop application that runs entirely on the user's own Windows computer. It has no server, no user database and no analytics. This policy explains what data the app touches and where it goes.

1. Data the app uses

  • Twitch stream and public chat of the user's own channel. The video is recorded to the user's computer and chat messages are read anonymously (no Twitch login) to detect exciting moments. Both stay on the user's computer.
  • TikTok account data, only if the user connects TikTok:
    • user.info.basic — the account's open ID, display name and avatar, used only to show which account is connected.
    • video.upload — used only to upload clips the app created to the user's own TikTok inbox as drafts. Nothing is published publicly by the app; the user decides in the TikTok app whether to post.
  • YouTube / Google account data, only if the user connects YouTube: permission to upload videos (youtube.upload) to the user's own channel. Videos are uploaded as private.
  • Access tokens issued by TikTok and Google after the user authorizes the app.

2. Where data is stored

All data, including clips and access tokens, is stored only in the app's folder on the user's own computer (the credentials folder for tokens). The developer of ClipWatcher never receives, sees or stores any of it.

3. Who data is shared with

Clips are sent only to the platforms the user connected (TikTok and/or YouTube), using their official APIs, into the user's own accounts. No data is sold, shared with third parties, or used for advertising or profiling.

4. Google API Services

ClipWatcher's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

5. Retention and deletion

  • Tokens are kept until the user disconnects. To disconnect, delete the files in the credentials folder and/or revoke access in TikTok (Settings › Security › Manage app permissions) or in your Google account permissions.
  • Recordings and clips stay on the user's computer until the user deletes them.

6. Children

ClipWatcher is not directed to children under 13 (or the minimum age in your country) and does not knowingly process their data.

7. Changes and contact

Changes to this policy are published on this page. Questions: contact the developer through the Twitch channel twitch.tv/eroplay01.

Política de Privacidade (resumo em português)

O ClipWatcher roda só no computador do próprio usuário. Não tem servidor nem banco de dados. A live e o chat público ficam no seu PC. Se você conectar o TikTok, o app usa seu nome/avatar só para mostrar a conta conectada e envia os clipes para a sua caixa de entrada do TikTok como rascunho — você decide se posta. No YouTube, os vídeos sobem como privados. Os tokens de acesso ficam só na pasta credentials do seu PC; nada é vendido nem compartilhado. Para desconectar, apague essa pasta e/ou remova o acesso nas configurações do TikTok ou da Google.
